# 🧠 Desafios de Programação — Iago

Repo de prática deliberada de programação. **1 desafio por semana**, complexidade
crescente, foco em lógica, linguagens e arquitetura.

## Como usar

1. Clone o repo:
   ```bash
   git clone https://github.com/iago-fred/desafios-programacao.git
   cd desafios-programacao
   ```
2. Entre na pasta da semana atual (ex.: `semana-01/`).
3. Leia o `README.md` da semana (o enunciado + requisitos).
4. Resolva no arquivo indicado (ex.: `solucao.js`).
5. Rode e teste:
   ```bash
   node semana-01/solucao.js
   ```
6. Commit + push da sua solução, e avise a **Neon** para a revisão.

## Estrutura

```
desafios-programacao/
├── README.md          ← este arquivo
├── LOG.md             ← log de progressão (status de cada semana)
├── semana-01/         ← Desafio 1 (Normalizador de Pedidos)
│   ├── README.md      ← enunciado + requisitos
│   ├── solucao.js      ← <coloque sua solução aqui>
│   └── ...
├── semana-02/         ← (proposto em breve)
└── ...
```

## Regras

- **Lógica antes de framework** — o framework é só o meio.
- **Sem IA para entregar a resposta** — pode pesquisar sintaxe, mas o algoritmo é seu.
- **Critério de pronto sempre no README da semana** (o que conta como entregue).
- Cada semana é **pasta própria**, autocontida.

## Fluxo semanal

| Etapa | Quem | Quando |
|---|---|---|
| Propõe o desafio | Neon | início da semana |
| Resolve | Iago | até domingo |
| Revisão + feedback | Neon | depois da entrega |

Progresso fica registrado em [`LOG.md`](./LOG.md).
